Notificaciones

Copia de seguridad completa

Guarda un archivo con absolutamente todos tus datos, ideal para pasarlos a otro computador o navegador, o para tener un respaldo. Importar un archivo reemplaza todo lo que tengas guardado ahora.

Exportar / Importar en Excel

Descarga tus gastos y metas de ahorro en un archivo que abre bien en Excel, o carga uno con esas mismas columnas para agregar registros (esto no borra nada, solo suma lo nuevo).

Detalles del archivo (para quien quiera armarlo a mano) ▾

Columnas: Frecuencia, Nombre, Categoria, TipoDeGasto, Ambito, Monto, MetaTotal, FechaLimite, Estado. Frecuencia acepta Fijo, Variable, Ahorro, Deuda o Diario. Para Deuda: Monto es la cuota mensual y MetaTotal es el saldo actual. Para Diario: Nombre es la nota (opcional) y FechaLimite es la fecha del gasto.

Informe mensual / Guardar como PDF

Genera un informe completo del mes que elijas: resumen, gráficos de gasto por categoría y de distribución, más el detalle de gastos diarios, pagos programados y deudas. Si eliges el mes actual, el informe llega hasta hoy; si eliges un mes anterior, sale completo. En la ventana de impresión elige "Guardar como PDF" si prefieres un archivo.

Borrar datos

Esta acción no se puede deshacer. Borra todos los gastos y categorías guardados en este navegador, para siempre. Si no descargaste una copia de seguridad (arriba) antes de borrar, esos datos se pierden y no hay forma de recuperarlos. Lo mismo pasa si borras los datos de este sitio desde la configuración del navegador, o si usabas una ventana de incógnito/privada: se pierde todo sin aviso.
